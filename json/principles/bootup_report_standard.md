The definitive structure for agent incarnation reports, ensuring forensic density and cross-generational synchronization.

## Principles
- **Header & Identity**: The report must include Agent Name, Session ID, and a multi-paragraph name justification.
- **Superpowers & Inventory**: Mapping of specific repository tools to agent capabilities and an explicit Tool Inventory.
-  verify_environment.py: Validates baseline integrity.
-  metagit_map.py: Generates internal DNS.
-  register_agent.py: Anchors identity.
-  instantiate_hud.py: Automates WeDo migration.
-  context_prefetch.py: Inherits recent context.
-  metagit_pulse.py: Monitors metabolic heat.
- **Entry Protocol Actions**: Verification of substrate integrity, DNS mapping, and HUD instantiation.
- **The Friction Report (RNA to DNA)**: Identification of operational/structural friction and the synthesized Mission Chord.
- **Constraints & Levers**: Explicit mandates (No Tables, No Graphs) and references to the One-Word Glossary.
